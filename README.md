## 👨‍💻 Sobre mí

Soy estudiante de **Ingeniería en Sistemas** en la **Universidad Católica Nordestana — UCNE**, República Dominicana.

Me apasiona transformar ideas y necesidades reales en aplicaciones funcionales. He desarrollado proyectos web y de escritorio utilizando tecnologías como **React, JavaScript, Next.js, Supabase, Electron y SQLite**.

Durante mi formación he trabajado con autenticación de usuarios, bases de datos, consumo de APIs REST, operaciones CRUD, interfaces administrativas, aplicaciones offline y despliegues web.

Actualmente busco oportunidades como **Frontend Developer Junior**, **React Developer** o **Software Developer Intern**, especialmente en equipos donde pueda aportar, adquirir experiencia profesional y continuar fortaleciendo mis habilidades.
